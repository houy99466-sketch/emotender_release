# EmoTend Editorial UI Redesign Design

## Goal

将现有浅色饮品界面改造成方案一的编辑感饮品杂志风格，同时完整保留当前产品行为、数据流、表情系统和所有功能入口。

## Approved Direction

- 使用纸张感浅色背景、衬线标题、无衬线正文和等宽分区编号。
- 使用珊瑚色作为主要操作色，青绿色作为数据和状态辅助色。
- 强调留白、细分隔线、非对称编辑排版和内容层级。
- 保留当前六组 SVG 表情、情绪颜色和动画，不使用预览稿中的示意笑脸。
- 移动端优先，桌面端使用更宽的编辑版心，不做营销页或新增页面。

## Immutable Functional Surface

以下内容不得改动：

- `static/index.html` 中全部 `<script>` 内容。
- `#crt-screen` 内的 SVG 节点、分组 ID、路径和动画语义。
- 全部现有 `id`、`onclick`、`data-*`、`aria-*` 和表单字段。
- 对话、推荐确认、规格调整、空间方案、最终报告、图片导出、登录退出、录音和文字输入流程。
- 后端文件、Prompt、饮品数据、情绪判断和 API 路径。

## Visual Changes

- 增加纯展示用途的品牌页眉，展示“此刻一杯 / EMOTEND · PERSONAL BEVERAGE”。
- 统一会话页、推荐确认页和最终报告页的版心、留白、细线和编辑标签。
- 让对话消息更接近杂志摘录和访谈排版，降低卡片感。
- 保持表情屏幕为原有实现，仅调整其外部尺寸、边框和页面关系。
- 将底部输入区改为纸面工具栏视觉，仍使用原输入框和原按钮。
- 调整规格弹窗、图表、构成示意、空间方案和小票的视觉样式，不改变交互。

## Responsive And Accessibility Rules

- 在 375px、768px、1024px 和 1440px 宽度下无水平滚动。
- 所有按钮和输入控件保持至少 44px 触控高度。
- 保留可见焦点样式，正文对比度满足 WCAG AA。
- 固定底栏为页面预留安全区和滚动空间。
- `prefers-reduced-motion: reduce` 下停用非必要动画和过渡。

## Verification

- 修改前后逐字比较全部 `<script>` 内容，结果必须相同。
- 修改前后比较功能 ID、`onclick` 和 `data-*` 属性集合，结果必须相同；新增静态品牌节点除外。
- 运行现有 Python 测试套件。
- 使用真实浏览器检查会话、推荐和报告三种状态的桌面与移动视口。
